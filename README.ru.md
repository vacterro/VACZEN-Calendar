# VACZEN Calendar

Чистое приложение календаря без отвлекающих факторов для управления личными задачами.

## Версия
0.0.1

[🤍 Поддержать разработчика](https://buymeacoffee.com/vacuum34)

## Возможности
- **Минималистичный интерфейс**: Без лишнего, только ваше расписание.
- **Управление задачами**: Отслеживайте важное.
- **Автономность**: Портативное и простое в развертывании.
- **Сохранение данных**: Хранение на основе JSON для задач и данных календаря.

## Установка
1. Клонируйте этот репозиторий
2. Установите Python 3.11 или выше
3. Запустите основной скрипт: `python zen_calendar_1.py`

## Использование
- Запустите приложение
- Добавляйте задачи и события в календарь
- Управляйте расписанием через чистый интерфейс
- Данные автоматически сохраняются в JSON файлы

## Файлы
- `zen_calendar_1.py` - Основное приложение календаря
- `zen_calendar_2.py` - Альтернативная реализация
- `zen_calendar_gpt.py` - Версия с улучшениями GPT
- `CalendarTask_data.json` - Хранение данных задач
- `ZenCalendar_data.json` - Хранение данных календаря

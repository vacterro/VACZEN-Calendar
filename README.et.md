# VACZEN Calendar

Puhas kalendrirakendus ilma segajateta isiklike ülesannete haldamiseks.

## Versioon
0.0.1

[🤍 Toetage arendajat](https://buymeacoffee.com/vacuum34)

## Funktsioonid
- **Minimaalne liides**: ilma segajateta, ainult teie ajakava.
- **Ülesannete haldus**: jälgige olulist.
- **Isejätkuv**: portatiivne ja lihtne juurutada.
- **Andmete püsivus**: JSON-põhine salvestus ülesannete ja kalendri andmete jaoks.

## Installimine
1. Kloonige see repopositoorium
2. Installige Python 3.11 või kõrgem
3. Käivitage peamine skript: `python zen_calendar_1.py`

## Kasutamine
- Käivitage rakendus
- Lisage ülesandeid ja sündmusi kalendrisse
- Haldage oma ajakava puhta liidese kaudu
- Andmed salvestatakse automaatselt JSON failidesse

## Failid
- `zen_calendar_1.py` - peamine kalendrirakendus
- `zen_calendar_2.py` - alternatiivne implementatsioon
- `zen_calendar_gpt.py` - GPT-täiustatud versioon
- `CalendarTask_data.json` - ülesannete andmete salvestus
- `ZenCalendar_data.json` - kalendri andmete salvestus

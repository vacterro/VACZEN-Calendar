## Features
- **Minimalist Interface**: No clutter, just your schedule.
- **Task Management**: Keep track of what matters.
- **Standalone**: Portable and easy to deploy.
- **Data Persistence**: JSON-based storage for tasks and calendar data.

## Installation
1. Clone this repository
2. Install Python 3.11 or higher
3. Run the main script: `python zen_calendar_1.py`

## Usage
- Launch the application
- Add tasks and events to your calendar
- Manage your schedule through the clean interface
- Data is automatically saved to JSON files

## Files
- `zen_calendar_1.py` - Main calendar application
- `zen_calendar_2.py` - Alternative implementation
- `zen_calendar_gpt.py` - GPT-enhanced version
- `CalendarTask_data.json` - Task data storage
- `ZenCalendar_data.json` - Calendar data storage
